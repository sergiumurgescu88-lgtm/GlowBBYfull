# ✨ Glowbby CRM

Studio Management Platform pentru Videochat

## 🚀 Features
- Dashboard cu statistici
- Leaderboard modele
- Top spenders globali
- Grafice evoluție USD/tokeni
- Hourly Heatmap
- Sugestii AI pentru traineri
- Import Excel automat

## 🛠️ Tech Stack
- **Backend:** Node.js + Express + SQLite
- **Frontend:** React + Vite + TailwindCSS
- **AI:** OpenRouter (Llama 3.1)

## 📦 Installation
```bash
git clone https://github.com/sergiumurgescu88-lgtm/glowbby.git
cd glowbby
npm install
cd frontend && npm install && npm run build && cd ..
cp .env.example .env
node server.js
```
